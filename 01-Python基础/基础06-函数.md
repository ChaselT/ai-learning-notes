# 基础06-函数

## 这是什么/为什么重要

Python 的函数是**一等公民**：可以独立于类存在、可以赋值给变量、可以当参数传递。这和"一切必须在类里"的 Java 完全不同，也是理解装饰器、回调、AI 框架 API 的基础。

## 核心内容

### 1. def：定义与调用

```python
def greet(name):
    """向某人问好。"""          # docstring：函数文档，≈ Javadoc
    return f"Hello, {name}!"

print(greet("Tom"))            # Hello, Tom!
```

```java
// Java 对照：必须挂在类上，必须声明返回类型和参数类型
public static String greet(String name) {
    return "Hello, " + name + "!";
}
```

没写 `return` 的函数返回 `None`：

```python
def log(msg):
    print(f"[LOG] {msg}")

result = log("hi")     # [LOG] hi
print(result)          # None
```

### 2. 返回多个值（其实是返回一个 tuple）

```python
def min_max(nums):
    return min(nums), max(nums)     # 逗号 = 打包成 tuple

lo, hi = min_max([3, 1, 4, 1, 5])   # 元组解包接收
print(lo, hi)                       # 1 5
```

```java
// Java 对照：要定义一个 record/类，或用 Pair —— Python 一行搞定
record MinMax(int min, int max) {}
```

### 3. 默认参数

```python
def connect(host, port=8080, timeout=30):
    print(f"连接 {host}:{port}，超时 {timeout}s")

connect("localhost")            # 连接 localhost:8080，超时 30s
connect("localhost", 9090)      # 连接 localhost:9090，超时 30s
```

大坑预警：**默认值只在函数定义时求值一次**，不要用可变对象当默认值：

```python
def add_item(item, items=[]):     # 错误示范！所有调用共享同一个 list
    items.append(item)
    return items

print(add_item(1))    # [1]
print(add_item(2))    # [1, 2]  ← 惊了！不是 [2]

def add_item_ok(item, items=None):    # 正确写法
    if items is None:
        items = []
    items.append(item)
    return items
```

### 4. 关键字参数调用

```python
def create_user(name, age, city):
    print(f"{name}, {age}, {city}")

create_user("Tom", 25, "Beijing")               # 位置参数
create_user(age=25, name="Tom", city="Beijing")  # 关键字参数：顺序随意，可读性高
create_user("Tom", city="Beijing", age=25)       # 混用：位置参数必须在前
```

Java 没有这个特性（只能靠 Builder 模式模拟），Python 里参数多的函数几乎都这么调。

### 5. *args 与 **kwargs：可变参数

```python
def total(*args):               # args 是 tuple，收集多余的位置参数
    print(args)
    return sum(args)

print(total(1, 2, 3))           # (1, 2, 3) 然后 6

def show(**kwargs):             # kwargs 是 dict，收集多余的关键字参数
    for k, v in kwargs.items():
        print(f"{k}={v}")

show(name="Tom", age=25)        # name=Tom / age=25
```

```java
// Java 对照：*args ≈ 可变参数 int... nums；**kwargs 无对应物（最接近 Map 参数）
```

反向操作——调用时用 `*`/`**` 把容器"摊开"成参数：

```python
nums = [1, 2, 3]
print(total(*nums))             # 等价于 total(1, 2, 3) → 6
```

### 6. lambda：匿名函数

```python
square = lambda x: x * x        # 只能写一个表达式，自动作为返回值
print(square(5))                # 25

nums = [3, -1, 2]
nums.sort(key=lambda x: abs(x)) # 最常见用法：当 key/回调
print(nums)                     # [-1, 2, 3]
```

```java
// Java 对照：x -> x * x，概念一致；Python 的 lambda 更受限（单表达式），
// 逻辑复杂就老老实实 def 一个函数
```

### 7. 作用域与 global

```python
count = 0

def incr():
    global count        # 不声明 global 的话，函数内赋值会创建局部变量
    count += 1

incr()
incr()
print(count)            # 2
```

规则：函数内**读**外层变量随意；函数内**赋值**默认创建局部变量，想改全局必须 `global`。实践中尽量少用 global，用返回值传递状态。

### 8. 函数即对象（为装饰器铺垫）

```python
def shout(text):
    return text.upper()

f = shout               # 函数赋值给变量（没有括号！括号是调用）
print(f("hello"))       # HELLO

def apply(func, value): # 函数当参数传
    return func(value)

print(apply(shout, "hi"))   # HI
print(apply(len, "hello"))  # 5
```

这就是 [[装饰器与上下文管理器]] 的地基：装饰器 = 接收函数、返回函数的函数。

### 9. 没有方法重载怎么办

```python
# Java: greet(String), greet(String, int) 两个重载
# Python: 同名 def 后者直接覆盖前者！用默认参数替代重载：
def greet(name, times=1):
    for _ in range(times):
        print(f"Hi, {name}")

greet("Tom")            # Hi, Tom
greet("Tom", times=3)   # 打印 3 次
```

参数类型不同的"重载"则靠动态类型天然支持，或用 `isinstance` 分支处理。

## 常见困惑

**Q1：为什么函数可以不写参数类型和返回类型？**
和变量一样是动态类型。正式代码推荐写注解：`def greet(name: str) -> str:`，工具会检查但运行时不强制，见 [[类型注解与typing]]。

**Q2：`f` 和 `f()` 的区别？**
`f` 是函数对象本身（可以传递、赋值），`f()` 才是调用。`nums.sort(key=len)` 传的是 `len` 这个对象——写成 `key=len()` 就错了。

**Q3：Python 传参是值传递还是引用传递？**
和 Java 一样是"传对象引用的值"：函数内重新赋值不影响外面，但对可变对象（list/dict）做修改，外面能看到。
