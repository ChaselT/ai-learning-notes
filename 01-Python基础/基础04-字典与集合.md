# 基础04-字典与集合

## 这是什么/为什么重要

dict 就是 Python 的 `HashMap`，set 就是 `HashSet`，但都是语言内置语法，不用 new、不用 import。dict 尤其重要：JSON、配置、API 返回值、关键字参数……Python 世界里到处都是 dict。

## 核心内容

### 1. 创建 dict：一对花括号

```python
user = {"name": "Tom", "age": 25, "city": "Beijing"}
empty = {}                          # 空 dict（注意：空 set 不能这么写，见下文）
scores = dict(math=90, english=85)  # 另一种写法，key 是标识符时可用

print(user)         # {'name': 'Tom', 'age': 25, 'city': 'Beijing'}
print(len(user))    # 3
```

```java
// Java 对照
Map<String, Object> user = new HashMap<>();
user.put("name", "Tom");
user.put("age", 25);
// 或 Map.of("name", "Tom", "age", 25)
```

### 2. 取值与 KeyError（和 Java 的关键行为差异！）

```python
user = {"name": "Tom", "age": 25}

print(user["name"])        # Tom（方括号取值）
# print(user["email"])     # KeyError: 'email' —— key 不存在直接抛异常！
```

```java
// Java 对照：行为完全不同！
map.get("email");  // Java 返回 null，不报错
// Python 的 d["email"] 抛 KeyError；想要"查不到返回默认值"用 d.get()
```

安全取值用 `get`：

```python
print(user.get("email"))            # None（不存在返回 None，像 Java 的 get）
print(user.get("email", "无邮箱"))   # 无邮箱（可指定默认值，≈ getOrDefault）
print("email" in user)              # False（in 检查 key 是否存在，≈ containsKey）
```

### 3. 增、改、删

```python
user = {"name": "Tom"}
user["age"] = 25            # 新增（key 不存在就是加）
user["age"] = 26            # 修改（key 存在就是改，和 put 一样覆盖）
print(user)                 # {'name': 'Tom', 'age': 26}

del user["age"]             # 删除
age = user.pop("age", None) # 删除并返回值，带默认值就不怕 KeyError
print(user)                 # {'name': 'Tom'}
```

### 4. keys / values / items 与遍历

```python
user = {"name": "Tom", "age": 25}

print(list(user.keys()))    # ['name', 'age']
print(list(user.values()))  # ['Tom', 25]
print(list(user.items()))   # [('name', 'Tom'), ('age', 25)]（(key, value) 元组的列表）

for key in user:            # 直接遍历 dict = 遍历 key
    print(key, user[key])   # name Tom / age 25

for key, value in user.items():   # 最常用：元组解包同时拿 key 和 value
    print(f"{key} = {value}")     # name = Tom / age = 25
```

```java
// Java 对照
for (Map.Entry<String, Object> e : map.entrySet()) {
    System.out.println(e.getKey() + " = " + e.getValue());
}
// Python 的 items() + 解包，比 entrySet 简洁得多
```

补充：Python 3.7+ 的 dict **保持插入顺序**（等于自带 LinkedHashMap 行为）。

### 5. set：去重与集合运算

```python
s = {1, 2, 3, 2, 1}
print(s)                    # {1, 2, 3}（自动去重，无序）

nums = [1, 2, 2, 3, 3, 3]
unique = set(nums)          # list 去重的惯用法
print(unique)               # {1, 2, 3}

s.add(4)
s.discard(1)                # 删除，不存在也不报错（remove 不存在会抛 KeyError）
print(s)                    # {2, 3, 4}
print(2 in s)               # True（in 判断成员，O(1)）

empty_set = set()           # 空 set 必须用 set()，{} 是空 dict！
```

交并差运算符（Java 要用 retainAll/addAll/removeAll，Python 一个符号搞定）：

```python
a = {1, 2, 3}
b = {2, 3, 4}
print(a & b)    # {2, 3}      交集（intersection）
print(a | b)    # {1, 2, 3, 4} 并集（union）
print(a - b)    # {1}          差集（在 a 不在 b）
print(a ^ b)    # {1, 4}       对称差（只在其中一边）
```

## 常见困惑

**Q1：为什么 `d["k"]` 查不到要抛异常，而不是像 Java 返回 null？**
Python 的哲学是"错误不应悄悄溜走"：查一个不存在的 key 多半是 bug，抛 KeyError 让你立刻发现。明确允许缺失时才用 `get(k, default)`。这与 [[基础08-异常处理]] 里的 EAFP 风格一脉相承。

**Q2：dict 的 key 能用什么类型？**
任何**不可变（可哈希）**的类型：str、int、tuple 都行；list、dict、set 不行（会抛 TypeError）。相当于 Java 里 key 必须正确实现 hashCode/equals，Python 用"不可变"这个条件替你把关。

**Q3：`{}` 到底是 dict 还是 set？**
是空 **dict**。花括号语法 dict 先到先得，空 set 只能写 `set()`。这是新手必踩的坑，踩一次就记住了。
