# 基础01-变量与基本类型

## 这是什么/为什么重要

变量和基本类型是任何语言的第一课。Python 与 Java 最大的心理落差就在这里：**不用声明类型、不用分号、不用类包裹代码**。这一篇帮你把 Java 的"仪式感"卸下来，建立 Python 的最小心智模型。

## 核心内容

### 1. 变量：不用声明类型，直接赋值

```python
x = 1
name = "Alice"
price = 9.9
is_ok = True

print(x)      # 1
print(name)   # Alice
print(price)  # 9.9
print(is_ok)  # True
```

```java
// Java 对照：必须声明类型
int x = 1;
String name = "Alice";
double price = 9.9;
boolean isOk = true;
System.out.println(x);
```

要点：
- 变量名指向对象，类型跟着**值**走，不跟着变量走（动态类型）。
- 命名习惯用 `snake_case`（下划线），不是 Java 的 `camelCase`。
- 没有分号，没有 `public static void main` —— 脚本从第一行直接执行。

### 2. 动态类型初体验

```python
x = 1
print(type(x))   # <class 'int'>

x = "hello"      # 同一个变量可以改指向别的类型，Java 里这是编译错误
print(type(x))   # <class 'str'>
```

```java
// Java 对照：下面第二行编译不通过
int x = 1;
x = "hello";  // error: incompatible types
```

灵活的代价是错误推迟到运行时才暴露。工程上会用类型注解补救，先不展开，见 [[类型注解与typing]]。

### 3. 五个最基本的类型

```python
a = 42          # int：整数，没有 int/long 之分，任意大小不溢出
b = 3.14        # float：对应 Java 的 double
c = "hi"        # str：字符串，没有 char 类型，单个字符也是 str
d = True        # bool：注意首字母大写！True/False，不是 true/false
e = None        # NoneType：对应 Java 的 null

print(a, b, c, d, e)  # 42 3.14 hi True None
print(2 ** 100)       # 1267650600228229401496703205376（int 不会溢出）
```

```java
// Java 对照
long a = 42L;        // Python 的 int 无上限，Java long 会溢出
double b = 3.14;
String c = "hi";
boolean d = true;    // 小写
Object e = null;     // null vs None
```

判断是否为 None，习惯用 `is`：

```python
result = None
if result is None:          # 不写 result == None
    print("还没有结果")      # 还没有结果
```

### 4. print 与 input

```python
print("Hello, Python")            # Hello, Python
print("a", "b", 123)              # a b 123（多个参数自动用空格连接）

name = input("你的名字：")         # input 返回的一定是 str
print("你好,", name)              # 你好, <你输入的内容>
```

```java
// Java 对照
System.out.println("Hello, Java");
Scanner sc = new Scanner(System.in);
String name = sc.nextLine();
```

### 5. f-string：字符串插值（比 Java 的 + 拼接舒服得多）

```python
name = "Bob"
age = 30
print(f"{name} is {age} years old")       # Bob is 30 years old
print(f"明年 {age + 1} 岁")                # 明年 31 岁（大括号里可以放表达式）
```

```java
// Java 对照
System.out.println(name + " is " + age + " years old");
// 或 String.format("%s is %d years old", name, age)
```

### 6. 类型转换：int() / str() / float()

```python
s = "123"
n = int(s)            # str -> int
print(n + 1)          # 124

x = 42
print("值是" + str(x))  # 值是42（str 和 int 不能直接用 + 拼接，必须显式转换）

age = int(input("年龄："))  # input 返回 str，算数前要先转
print(age * 2)
```

注意：Java 里 `"值是" + 42` 会自动转字符串，Python 会直接抛 `TypeError`，必须 `str(x)` 或用 f-string。

### 7. 除法：/ 与 //，还有 ** 幂运算

```python
print(7 / 2)    # 3.5   → / 永远返回 float（Java 的 7/2 得 3！）
print(7 // 2)   # 3     → // 才是整除，向下取整
print(-7 // 2)  # -4    → 注意是向下取整，不是向零取整（Java 的 -7/2 得 -3）
print(7 % 2)    # 1     → 取余和 Java 一样
print(2 ** 10)  # 1024  → ** 是幂运算，Java 要用 Math.pow
```

## 常见困惑

**Q1：不声明类型也不报错，写错了怎么办？**
类型错误会推迟到运行时才炸（如 `"a" + 1` 抛 TypeError）。小脚本靠立刻运行验证；正式项目靠类型注解 + IDE 检查，详见 [[类型注解与typing]]。

**Q2：为什么 `7 / 2` 是 3.5 而不是 3？**
Python 3 的 `/` 是"真除法"，永远返回 float。想要 Java 那种整数除法，用 `//`。这是 Java 工程师最容易踩的第一个坑。

**Q3：`None` 和 `null` 完全一样吗？**
概念相似，但 `None` 本身是一个真实对象（NoneType 的唯一实例），可以 `print(None)`、可以当默认参数。判断时用 `x is None` 而不是 `==`。
