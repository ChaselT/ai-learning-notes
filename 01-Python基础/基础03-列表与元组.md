# 基础03-列表与元组

## 这是什么/为什么重要

list 是 Python 里最常用的容器，相当于 Java 的 `ArrayList`，但写法轻得多——不用 new、不用泛型声明、什么类型都能装。tuple 是"不可变的 list"，是 Python 特有的常用结构（多返回值、解包都靠它）。

## 核心内容

### 1. 创建 list：一对方括号搞定

```python
nums = [1, 2, 3]
names = ["Tom", "Jerry"]
mixed = [1, "two", 3.0, True]   # 可以混装不同类型（Java 泛型工程师先深呼吸）
empty = []

print(nums)        # [1, 2, 3]
print(len(nums))   # 3
```

```java
// Java 对照
List<Integer> nums = new ArrayList<>(List.of(1, 2, 3));
// Python 没有泛型声明；要约束类型得靠注解 list[int]，见 [[类型注解与typing]]
```

### 2. 增删改查

```python
nums = [1, 2, 3]

nums.append(4)          # 尾部追加一个元素
print(nums)             # [1, 2, 3, 4]

nums.extend([5, 6])     # 追加另一个列表的所有元素（≈ addAll）
print(nums)             # [1, 2, 3, 4, 5, 6]

nums.insert(0, 99)      # 在下标 0 处插入
print(nums)             # [99, 1, 2, 3, 4, 5, 6]

nums.remove(99)         # 按值删除第一个匹配项（找不到会抛 ValueError）
print(nums)             # [1, 2, 3, 4, 5, 6]

last = nums.pop()       # 弹出并返回最后一个元素
print(last, nums)       # 6 [1, 2, 3, 4, 5]

first = nums.pop(0)     # 弹出指定下标
print(first, nums)      # 1 [2, 3, 4, 5]

nums[0] = 20            # 按下标改值
print(nums)             # [20, 3, 4, 5]
print(nums[0])          # 20（按下标取值，和数组一样）
print(4 in nums)        # True（in 判断包含，= contains）
```

注意 `append` vs `extend`：`append([5, 6])` 会把整个列表当**一个元素**塞进去，得到 `[..., [5, 6]]`。

### 3. 排序

```python
nums = [3, 1, 2]
nums.sort()                 # 原地排序，返回 None！
print(nums)                 # [1, 2, 3]

nums.sort(reverse=True)
print(nums)                 # [3, 2, 1]

a = [3, 1, 2]
b = sorted(a)               # sorted() 返回新列表，原列表不动
print(a, b)                 # [3, 1, 2] [1, 2, 3]

words = ["bb", "a", "ccc"]
words.sort(key=len)         # 按 key 函数结果排序（≈ Comparator.comparing）
print(words)                # ['a', 'bb', 'ccc']
```

坑：`x = nums.sort()` 会得到 `None`，因为 sort 原地修改不返回值。

### 4. 切片：和字符串完全一样

```python
nums = [0, 1, 2, 3, 4, 5]
print(nums[1:4])    # [1, 2, 3]
print(nums[-2:])    # [4, 5]
print(nums[::-1])   # [5, 4, 3, 2, 1, 0]（反转）
copy = nums[:]      # 浅拷贝一份（直接 b = nums 只是复制引用，和 Java 一样）
```

### 5. tuple：不可变的"列表"

```python
point = (3, 5)          # 圆括号创建
print(point[0])         # 3（读取和 list 一样）
# point[0] = 10         # TypeError！tuple 不可变

single = (42,)          # 只有一个元素时必须带逗号，(42) 只是数字 42
```

用途：当"一组不会变的值"用（坐标、日期、函数多返回值），可以作 dict 的 key（list 不行）。

### 6. 元组解包（Python 名场面）

```python
a, b = 1, 2             # 一行赋两个值（右边其实是 tuple (1, 2)）
print(a, b)             # 1 2

a, b = b, a             # 交换变量！不需要 temp 中间变量
print(a, b)             # 2 1

x, y, z = [10, 20, 30]  # list 也能解包
print(x, y, z)          # 10 20 30

first, *rest = [1, 2, 3, 4]   # * 收集剩余元素
print(first, rest)      # 1 [2, 3, 4]
```

```java
// Java 对照：交换变量必须借助临时变量
int temp = a; a = b; b = temp;
```

### 7. 嵌套列表

```python
matrix = [
    [1, 2, 3],
    [4, 5, 6],
]
print(matrix[1][2])     # 6（第 2 行第 3 列）
print(matrix[0])        # [1, 2, 3]（第一行本身是个 list）
matrix[0].append(99)
print(matrix[0])        # [1, 2, 3, 99]
```

## 常见困惑

**Q1：没有泛型，列表里混装类型不慌吗？**
语法上允许，但工程实践中同一个 list 几乎总是装同一种类型，靠类型注解 `list[int]` 表达约束（见 [[类型注解与typing]]）。混装是灵活性，不是推荐做法。

**Q2：list 到底是数组还是链表？**
底层是动态数组，等价于 `ArrayList`：随机访问 O(1)，尾部 append 均摊 O(1)，头部 insert/pop(0) 是 O(n)。需要队列用 `collections.deque`。

**Q3：什么时候用 tuple 而不是 list？**
数据"结构固定、不会增删"就用 tuple（如坐标、函数多返回值）；会动态增删就用 list。tuple 不可变，所以更安全、可哈希、可当 dict key。
