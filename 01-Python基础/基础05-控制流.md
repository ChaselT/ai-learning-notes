# 基础05-控制流

## 这是什么/为什么重要

这一篇是 Java 工程师"换脑子"最集中的地方：**缩进就是代码块**（没有花括号）、**for 不是 C 风格**、**空容器就是 False**。把这三点吃透，读任何 Python 代码都不再别扭。

## 核心内容

### 1. if / elif / else：无括号、缩进即块

```python
score = 85

if score >= 90:
    print("优秀")
elif score >= 60:          # elif = Java 的 else if
    print("及格")           # 缩进 4 个空格 = 代码块，没有花括号
else:
    print("不及格")
# 输出：及格
```

```java
// Java 对照
if (score >= 90) {
    System.out.println("优秀");
} else if (score >= 60) { ... }
```

要点：条件不用圆括号；行尾冒号 `:` 开启代码块；**缩进错了就是语法错误或逻辑错误**，IDE 会帮你，但心里要有弦。逻辑运算符是英文单词：`and` / `or` / `not`（不是 `&&` `||` `!`）。

```python
age = 25
if age >= 18 and age < 60:
    print("成年劳动力")     # 成年劳动力
if 18 <= age < 60:          # 还可以链式比较！Java 没有
    print("同上")           # 同上
```

### 2. 真值测试（重点！Java 没有的概念）

Java 的 if 只接受 boolean；Python 的 if 接受**任何值**，按规则自动判真假：

```python
# 以下都是"假值"（falsy）：
print(bool(0))        # False
print(bool(""))       # False（空字符串）
print(bool([]))       # False（空列表）
print(bool({}))       # False（空 dict）
print(bool(None))     # False
# 除此之外几乎都是 True，包括 "0"、[0]、-1

items = []
if not items:                 # 惯用法：判断列表为空
    print("列表是空的")        # 列表是空的

name = ""
if name:                      # 惯用法：判断字符串非空
    print(f"你好 {name}")
else:
    print("名字没填")          # 名字没填
```

```java
// Java 对照：必须显式写条件
if (items.isEmpty()) { ... }
if (name != null && !name.isEmpty()) { ... }
// Python 一句 if not items / if name 全包了
```

### 3. for-in：遍历，不是 C 风格计数

Python 的 for 只有一种：遍历可迭代对象（≈ Java 的 for-each）。

```python
for fruit in ["apple", "banana", "cherry"]:
    print(fruit)          # 依次打印三种水果

for ch in "abc":
    print(ch)             # a / b / c（字符串也能遍历）
```

需要下标计数时用 `range`：

```python
for i in range(5):        # 0,1,2,3,4（含 0 不含 5）
    print(i)

for i in range(2, 10, 3): # 从 2 到 10（不含），步长 3
    print(i)              # 2 / 5 / 8
```

```java
// Java 对照
for (int i = 0; i < 5; i++) { ... }   // Python: for i in range(5)
for (String f : fruits) { ... }        // Python: for f in fruits
```

### 4. enumerate 与 zip（告别手动维护下标）

```python
fruits = ["apple", "banana"]
for i, fruit in enumerate(fruits):        # 同时拿下标和元素
    print(i, fruit)                       # 0 apple / 1 banana

names = ["Tom", "Jerry"]
ages = [25, 30]
for name, age in zip(names, ages):        # 并行遍历两个列表
    print(f"{name}: {age}")               # Tom: 25 / Jerry: 30
```

### 5. while 与 break / continue

```python
n = 0
while n < 5:
    n += 1                # 没有 n++！只有 += 
    if n == 2:
        continue          # 跳过本次
    if n == 4:
        break             # 跳出循环
    print(n)              # 1 / 3
```

### 6. match-case：Python 3.10+ 的"switch"

```python
status = 404

match status:
    case 200:
        print("OK")
    case 404:
        print("Not Found")        # Not Found
    case 500 | 502:               # 多值匹配用 |
        print("Server Error")
    case _:                       # _ = default
        print("Unknown")
```

```java
// Java 对照：switch (status) { case 404 -> ...; default -> ...; }
// match 还支持结构匹配（解包 tuple/dict/对象），比 switch 强大，入门先会常量匹配即可
```

### 7. 三元表达式：a if cond else b

```python
age = 20
label = "成年" if age >= 18 else "未成年"    # 注意语序：结果在前，条件在中间
print(label)                                # 成年
```

```java
// Java 对照：String label = age >= 18 ? "成年" : "未成年";
// 语序不同：Java 是 条件?真值:假值，Python 是 真值 if 条件 else 假值
```

## 常见困惑

**Q1：缩进用 Tab 还是空格？缩进几格？**
社区标准：**4 个空格**。IDE（VS Code/PyCharm）默认会把 Tab 键转成 4 空格，不要混用，混用直接 `IndentationError`。

**Q2：没有 C 风格 for，想要"倒着数"或"跳着数"怎么办？**
`range` 全能：`range(10, 0, -1)` 就是 10 到 1 倒数。真需要遍历时改下标的场景，重新想想——多半 enumerate 或切片能更优雅地解决。

**Q3：`if x:` 和 `if x is not None:` 一样吗？**
不一样！`if x:` 在 x 为 0、""、[] 时也是 False。如果"0 是合法值、只想排除 None"，必须写 `if x is not None:`。这是真值测试最经典的坑。
