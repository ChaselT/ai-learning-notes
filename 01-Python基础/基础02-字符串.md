# 基础02-字符串

## 这是什么/为什么重要

字符串是日常代码里出现最多的类型。Python 的 str 比 Java String 顺手得多，尤其是**切片语法**——这是 Java 完全没有的东西，也是后面 list、AI 数据处理（numpy/pandas）都在用的通用语法，这一篇必须讲透。

## 核心内容

### 1. 三种引号

```python
a = 'hello'          # 单引号
b = "world"          # 双引号，和单引号完全等价
c = "it's ok"        # 字符串里有单引号时，外面用双引号就不用转义
d = """第一行
第二行
第三行"""             # 三引号：多行字符串（类似 Java 15+ 的文本块）

print(a, b)   # hello world
print(c)      # it's ok
print(d)      # 三行内容原样输出
```

```java
// Java 对照：只能双引号；'a' 是 char，Python 没有 char 类型
String a = "hello";
String d = """
    第一行
    第二行""";  // Java 15+ text block
```

### 2. 不可变性：和 Java String 一样

```python
s = "hello"
# s[0] = "H"        # TypeError！str 不可变，和 Java String 相同
s2 = s.upper()      # 所有"修改"方法都返回新字符串
print(s)            # hello（原串不变）
print(s2)           # HELLO
```

### 3. 索引与切片（重点！Java 没有的语法）

索引：`s[i]` 取单个字符，**负数从尾部倒着数**。

```python
s = "Python"
print(s[0])    # P     （相当于 Java 的 s.charAt(0)）
print(s[5])    # n
print(s[-1])   # n     （最后一个字符，Java 要写 s.charAt(s.length()-1)）
print(s[-2])   # o
print(len(s))  # 6     （长度是函数 len(s)，不是 s.length()）
```

切片：`s[start:stop]`，**含 start，不含 stop**（左闭右开，和 substring 一样）。

```python
s = "Python"
print(s[1:3])    # yt      （相当于 s.substring(1, 3)）
print(s[:2])     # Py      （省略 start = 从头开始）
print(s[2:])     # thon    （省略 stop = 直到结尾）
print(s[-3:])    # hon     （最后 3 个字符）
print(s[:])      # Python  （完整拷贝）
```

第三个参数是步长 `s[start:stop:step]`：

```python
s = "Python"
print(s[::2])    # Pto     （每隔一个取一个）
print(s[::-1])   # nohtyP  （步长 -1 = 反转字符串，Java 要 new StringBuilder(s).reverse()）
```

切片越界**不报错**，这点和索引不同：

```python
s = "abc"
# print(s[10])   # IndexError：索引越界会炸
print(s[1:100])  # bc（切片越界自动截断，很宽容）
```

### 4. 常用方法

```python
s = "  a,b,c  "
print(s.strip())              # "a,b,c"          （去两端空白，= Java trim/strip）
print("a,b,c".split(","))     # ['a', 'b', 'c']  （返回 list）
print("-".join(["a", "b"]))   # a-b              （注意：连接符在前，列表在后！）
print("hello".replace("l", "L"))   # heLLo
print("hello".startswith("he"))    # True
print("hello".endswith("lo"))      # True
print("HELLO".lower())             # hello
print("hello".upper())             # HELLO
print("ab" * 3)                    # ababab（字符串可以乘法重复）
```

```java
// Java 对照
"a,b,c".split(",");            // 返回 String[]
String.join("-", List.of("a", "b"));  // Python 是 "-".join(list)，方向相反
```

### 5. in 操作符：判断包含

```python
s = "hello world"
print("world" in s)      # True   （= Java 的 s.contains("world")）
print("xyz" not in s)    # True
```

### 6. f-string 进阶：格式化

大括号里冒号后面写格式说明：

```python
pi = 3.14159
n = 1234567
pct = 0.856

print(f"{pi:.2f}")       # 3.14       （保留 2 位小数）
print(f"{n:,}")          # 1,234,567  （千分位）
print(f"{pct:.1%}")      # 85.6%      （百分比）
print(f"{42:5d}")        # "   42"    （宽度 5，右对齐）
print(f"{'ab':<6}|")     # "ab    |"  （宽度 6，左对齐）
print(f"{'ab':>6}|")     # "    ab|"  （右对齐）
print(f"{'ab':^6}|")     # "  ab  |"  （居中）
print(f"{pi=}")          # pi=3.14159 （调试神器：自动打印 变量名=值）
```

```java
// Java 对照：String.format("%.2f", pi)，功能类似但没有 {pi=} 这种调试写法
```

## 常见困惑

**Q1：为什么是 `len(s)` 而不是 `s.length()`？**
Python 把"取长度"设计成内置函数 `len()`，对 str/list/dict 等所有容器通用。习惯就好，这是 Python 的统一协议风格（背后是 `__len__` 魔法方法，到 [[基础07-类与对象]] 会再遇到）。

**Q2：join 为什么写成 `"-".join(list)`，连接符调用方法？**
因为被连接的可以是任何可迭代对象，把方法放在 str 上最通用。记忆口诀："用什么连，就在什么上调 join"。

**Q3：单引号和双引号到底用哪个？**
完全等价，团队统一即可。格式化工具（如 ruff format）默认统一成双引号，跟着工具走就行。
