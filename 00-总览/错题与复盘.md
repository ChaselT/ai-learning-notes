## 阶段 0：Python 基础

- 2026-07-24 · uv 篇实操：`uv add httpx pydantic` 把原有的 `httpx[socks]` 覆盖成裸 httpx，socksio 被移除导致代理报错。**正确理解**：uv add 对同名包是声明式覆盖，重新 add 会以新写法为准；本机必须写 `uv add "httpx[socks]"`。关联：[[uv与项目管理]]、[[硬件与环境]]
- 2026-07-24 · b01 练习：变量定义在顶层写了一遍、main() 里又写一遍，直接运行打印两次。**正确理解**：顶层语句无条件执行；规范是顶层只放 import/def/常量，逻辑进函数由 `if __name__ == "__main__"` 触发。关联：[[基础09-模块与导入]]
- 2026-07-24 · 环境实验：demo_import.py 运行无任何输出，原因是 VS Code 未保存（磁盘上 0 字节）。**正确理解**：uv run 读磁盘文件不读编辑器缓冲区；排查第一步永远是确认文件真实内容；已开 Auto Save。
- 2026-07-24 · 检验题知识点：Python `/` 永远返回 float（8/2 → 4.0），Java 的整数 `/` ≈ Python 的 `//`；负数时 Java 向零截断（-7/2=-3）、Python 向负无穷取整（-7//2=-4）。关联：[[基础01-变量与基本类型]]
- 2026-07-28 · pydantic 课：①`dataclasses.field` 误用进 BaseModel（pydantic 用大写 `Field`，两套框架别混搭）；②打印了实例的 `model_dump_json()` 却以为是类的 `model_json_schema()`——**前者是一份数据，后者是格式说明书（喂 LLM 用的）**；③Schema 的 required 由"有无默认值"决定，是和 LLM 的合同条款。关联：[[dataclass与pydantic]]
- 2026-07-28 · 命名：`except ... as e` 之后拿 `e` 装业务对象（mypy [misc] 抓获）——e 约定俗成属于异常。
- 2026-07-28 · 拼写立户头：rander→boadcast→boardcast 三连击。**对策**：函数名写完默读一遍；Pylance typeCheckingMode 已开 basic（能抓大部分此类错）。
- 2026-07-28 · "没报错"假象：Pylance 类型检查默认 off，光看编辑器没红线 ≠ 类型没问题——要么跑 mypy，要么开 basic 模式。另：mypy 不检查无注解函数的函数体（main 不写 -> None 就是免检区）。关联：[[类型注解与typing]]
- 2026-07-28 · 设计观：参数已注解 `msg: str` 就别再防 None——类型契约由检查器守卫，冗余防御是对类型系统的不信任；Protocol 是纯契约，方法体只写 `...`。关联：[[类型注解与typing]]
- 2026-07-27 · duck_typing 练习：方法名拼成 `rander` 但两类错得一致、程序照跑——鸭子类型只查名字存在、不查名字正确，无编译期保护（Java interface 会当场抓住）。**正确理解**：这正是 Protocol + 类型检查存在的意义（进阶篇待学）。关联：[[Python与Java核心差异]]、[[类型注解与typing]]
- 2026-07-27 · 知识点：CPython 小整数缓存池 -5~256（同 Java Integer.valueOf 的 -128~127），故 `5 is 5` 为 True 但属实现细节——`is` 仅用于 None，值比较一律 `==`。关联：[[Python与Java核心差异]]
- 2026-07-27 · 流程复犯："修复了"实际只改了一个文件、列表实验没加——"完成"= 改了+跑了+看到输出，三步缺一不可（第二次犯）。
- 2026-07-26 · b07 双层 bug：①`类名.balance = 100` 把 property 描述符整个覆盖成 int，setter 随之消失（"setter 不生效"的真凶）；②getter/setter 内用 `self.balance` 自己触发自己 → RecursionError。**正确理解**：property 占据类属性名；存储字段用 `self._balance` 错开；永远别对类名赋值实例数据。关联：[[基础07-类与对象]]
- 2026-07-26 · b07：变量命名 `list` 遮蔽内置类型（命名问题第三次：scores→score→list）。**正确理解**：list/dict/str/type 等内置名不可作变量名；起名前想"这词是否已有主"。关联：[[基础07-类与对象]]
- 2026-07-26 · b07 检验：Python 子类 __init__ 不自动调父类（Java 自动插 super()），漏调则父类字段静默缺失，访问时才 AttributeError——炸点远离病根。已实验验证。关联：[[基础07-类与对象]]
- 2026-07-26 · b06：题目要求函数"返回"描述，写成了 print。**正确理解**：函数负责算、调用方决定怎么用；print 版调用方只能拿到 None。附带：`describe("Alice", "25")` 把 int 传成 str 无人拦截——这就是类型注解存在的意义。关联：[[基础06-函数]]、[[类型注解与typing]]
- 2026-07-26 · b06：avg 加了空列表护栏但 min/max 没加，`stats()` 空调用照样炸 `ValueError`；验证完的炸弹代码忘删导致脚本必崩。**正确理解**：护栏要么全护要么不护；改完必重跑再交。关联：[[基础06-函数]]、[[基础08-异常处理]]
- 2026-07-26 · 推导式初理解漏了"收集"：`[f(x) for x in xs]` ≠ 裸循环调 f(x)，本质是**循环 + 把每个结果收进新列表**。关联：[[基础06-函数]]
- 2026-07-25 · b03 检验题：以为 `first, *rest = [10]` 时 rest 是 int。**正确理解**：星号解包目标无论接到几个元素恒为 list（0 个时为 `[]`）。关联：[[基础03-列表与元组]]
- 2026-07-25 · b03/b04：`s.sort()` 原地排序返回 None（`s = s.sort()` 是灭顶之灾）；set 根本没有 sort 方法。**正确理解**：要排序先想 `sorted()`——通吃一切可迭代对象、返回新 list。关联：[[基础03-列表与元组]]
- 2026-07-25 · b05 真 bug：`range(1, 30)` 漏了 30，恰好漏掉唯一的 FizzBuzz(30)。**正确理解**：Python 所有区间（range/切片）统一含头不含尾，写区间时默念"尾巴要 +1"。关联：[[基础05-控制流]]
- 2026-07-25 · b05 风格：①三元表达式被当 if 语句用（`print(A) if c else print(B)`），正确姿势是产出值（`print(A if c else B)`）；②列表 `score` 与循环变量 `score` 同名遮蔽，规范：容器复数、元素单数。关联：[[基础05-控制流]]
- 2026-07-24 · b02 练习：`price = 100.00` 打印出 `100.0`——float 变量不存储小数位格式，两位小数要在输出时用 `{x:.2f}` 控制（可与宽度连写 `{x:>10.2f}`）。**附带教训**：join 用了 `"|"` 注释却写"逗号"，注释说谎比没注释更糟。关联：[[基础02-字符串]]
