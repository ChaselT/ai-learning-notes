# 硬件与环境

## 本机配置

| 项目 | 配置 | 对 AI 学习的意义 |
|------|------|------------------|
| GPU | RTX 2080 Ti 魔改 22GB 显存 | 本地推理 14B（Q5）无压力，32B-Q4 可跑；QLoRA 微调 14B；CV 训练大 batch |
| CPU | i7-13700KF（16 核） | 数据预处理、并行实验充足 |
| 内存 | 64GB | 大数据集加载、模型量化转换无忧 |
| CUDA | 13.1（驱动 591.86） | 装 PyTorch 时选对应 CUDA 版本的 wheel |
| 系统 | Windows 11 Pro | 阶段 4 建议启用 WSL2（vLLM 等只支持 Linux） |

## 本机能力边界（速查）

- **推理**：7B/8B 全精度、14B Q5 流畅、32B Q4 勉强（上下文别开太长）
- **LLM 微调**：QLoRA 14B ✅ / LoRA 7B ✅ / 全参微调 7B ❌（需多卡）
- **CV 训练**：图像分类、YOLO 检测随便跑，22G 可以开很大的 batch
- **注意**：2080 Ti 是 Turing 架构（sm_75），不支持 BF16 原生加速，训练用 FP16；个别新库可能放弃 sm_75 支持，遇到时选旧版本或换库
